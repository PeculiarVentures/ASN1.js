# Validate against a schema

A schema is a tree of asn1js objects that describes the expected structure. `verifySchema()` decodes the bytes and checks them against it in one step. Give a block a `name` to read it from `result`, mark it `optional` when it may be missing, and use `Any` to accept any value.
