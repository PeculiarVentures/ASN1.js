# Read an X.509 certificate

Decode a PEM certificate and read its version, serial number, issuer, subject, and validity period with a schema for the parts of RFC 5280 you need. For full certificate support, including signature verification, use [PKIjs](https://pkijs.org), which is built on asn1js.
