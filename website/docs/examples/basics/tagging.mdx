# Explicit and implicit tags

Context-specific tags such as `[0]` appear in most real ASN.1 modules. An `EXPLICIT` tag wraps the original value in a constructed value. An `IMPLICIT` tag replaces the original tag, so the decoder returns a generic `Primitive` and you rebuild the original type from its content bytes.
